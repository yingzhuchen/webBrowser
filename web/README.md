# webBrowser 本地前端

在仓库根目录启动（先安装项目依赖）：

```bash
uv sync
uv run python web/server.py
```

打开 http://127.0.0.1:7860 。参考 Browser Use 的简洁任务界面，提供任务输入、模型设置、本地 / 云浏览器选择、任务记录和结果复制。无需 Node 或前端构建。

默认模型为 bu-fast，需要在服务端配置 `BROWSER_USE_API_KEY`（也可放在根目录 `.env`）。本地 Chromium 需安装 Chrome / Chromium。使用其他模型时，在设置中输入项目支持的模型字符串，并设置对应提供商的环境变量。云浏览器也需要 `BROWSER_USE_API_KEY`。实际运行会产生相应模型或云浏览器费用。

同一时间执行一个任务，最多 100 步，执行循环预算 300 秒；浏览器启动和清理可能需要额外时间。界面轮询状态，完成后显示真实结果，不提供浏览器视频流或逐步日志。任务记录只保存在服务内存中，重启清空，最多保留 50 条。

仅供本机使用，服务绑定 `127.0.0.1`，请勿通过端口转发公开。API 密钥不传给前端。不要在任务描述中粘贴密钥。
